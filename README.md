# HoopsOS

HoopsOS is a basketball themed web operating system which I have created using HTML, CSS, and JavaScript. HoopsOS has a variety of applications and tools plus drag and drop windows, taskbar, desktop widgets, app search, customization, and basketball themed boot screen.

## Getting Started

Open https://hoops-os.netlify.app/ in a browser window and interact with the desktop environment. Applications can be opened from the desktop, taskbar, menus, or search bar.

## Apps

### Playbook

The Playbook is a simple place to write and store notes. Notes are saved to your browser's local storage.

### Scoreboard

The Scoreboard lets you keep track of a game. Simply set your home and away team names and add or subtract points with the scoring buttons.

Also included is a live score widget on the desktop which displays the current score.

### Clock

The Clock contains three separate tools:

Shot Clock

Timer

Stopwatch

Use any of these tools while working with HoopsOS.

### Locker Room

The Locker Room displays suff about me. This includes my name, jersey number, position, and bio.

### Calculator

A standard calculator with all the basic buttons and functions.

### Stat Tracker

The Stat Tracker lets you keep track of basketball statistics. You can update the statistics and reset them for a new game.

### Schedule

The Schedule app lets you keep track of your upcoming games. You can edit games and add new games.

### Hoops Shootout

Hoops Shootout is a small basketball game where you can attempt to score as many points as you can before time runs out. You will have 20 seconds to score as many points as you can.

### Paint

Paint is a simple drawing application. You can change colors and brush sizes, switch between pen and eraser, clear the canvas, and save your image as a PNG file.

### Weather

The Weather app uses your location to display the current weather. The Weather app uses an online service to display the weather, so an internet connection is required.

### Browser

HoopsOS has a built in simple browser. Tabs, back/forward buttons, reload, and searching from the address bar are supported. There are also some shortcuts for Google, Wikipedia, and NBA.

Some websites may not be supported in the HoopsOS browser due to the way they are built. For some sites it may be necessary to open them up in a new tab.

### Terminal

The Terminal is a built in command line utility.

Some of the supported commands are:

```text

help

whoami

score

stats

clock

roster

ls

open

clear

date

echo

```

The Terminal also has a command history feature which can be accessed with the arrow keys.

### Watch

The Watch app contains videos and highlights. Videos can be played from YouTube when needed.

### Hall of Fame

The Hall of Fame contains cards of players and quick facts. It also includes links to NBA profiles.

### Settings

Settings lets you change many aspects of the OS.

You can customize:

Accent color

Desktop background

Icon size

Desktop icons

Clock widget

Mascot settings

Sound

Other appearance options

There is also an About section which contains information about HoopsOS.

## Desktop Features

HoopsOS has been designed to work more like a traditional desktop operating system rather than just a set of applications.

### App Search

The search bar allows you to quickly find an application. Just type in the name of the app and press enter to open it.

### Windows

Applications open in their own windows which can be moved around the desktop. The minimize, maximize, or close buttons can also be used.

### Taskbar

The taskbar provides quick access to open applications and parts of the OS.

### Desktop Widgets

There are basketball themed widgets on the desktop including a game clock and score.

### Context Menu

Right clicking on the desktop brings up a context menu with quick access to notes, games, terminal, display settings, and the Settings app. Touch devices can use a long press instead.

### Notifications

HoopsOS has a built in notifications system for displaying messages.

### Battery and Time

The top of the desktop displays the current time, battery percentage, and connection status.

## Design

I wanted HoopsOS to feel like a hybrid between a traditional desktop operating system and a basketball application. Most of HoopsOS' design uses dark themes along with basketball inspired colors and UI elements. The applications are designed to feel more like individual parts of an operating system rather than websites.

## Built With

HoopsOS is built with:

HTML

CSS

JavaScript

HoopsOS has been designed to run in web browsers without the need for a separate application or installation.

## Data and Storage

Some features make use of your browsers local storage to save data. This means notes and some other data can be saved in your browser. Some features require an internet connection such as the weather and videos.

## Using HoopsOS

There are no complicated steps to set up HoopsOS.

1. Open https://hoops-os.netlify.app/ in a web browser.

2. Wait for the system to boot up.

3. Click anywhere on the desktop to begin.

4. Open applications from the desktop, menus, taskbar, or search bar.

5. Customize your system with the Settings app.

6. Enjoy the basketball themed applications and games.

## Project Structure

This project is centered around a single HTML file which contains the interface, styles, and scripts required by HoopsOS.

I wanted to make this project as simple as possible to run locally while still providing a feeling of an operating system.

## About

HoopsOS began as an experiment of how far I could take a browser based interface. Instead of building yet another website, I wanted to build something which felt like a small operating system. I wanted to experiment with UI and JavaScript at the same time, and I wanted to create something around a sport which I enjoy. There is still plenty which can be added in the future, but this project is a fun interactive basketball themed desktop which can be run from your browser.
